## Два наблюдения, которые стоит вернуть в тред

**1. Расхождение по `pāla`.** В issue сказано «`pāla` is a suffix for 285 words in MW». Обратный
индекс даёт **183** левых члена. Разница не ошибка, а разные множества: advanced-search считает
все заголовки, оканчивающиеся на `-pāla` (включая не-композиты и случайные совпадения), тогда как
`compounds.txt` отражает только то, что MW сам разметил как деривацию, и здесь дополнительно
отброшены несоставные формы с `-`/`@`. Любое сравнение этих чисел должно оговаривать, какое
множество имеется в виду.

**2. Источник смешивает uttarapada композитов с деривационными суффиксами.** Верх списка по числу
левых членов:

| правый член | левых членов | что это на самом деле |
|---|---:|---|
| `tva` | 1246 | таддхита-суффикс, не слово |
| `vat` | 1136 | таддхита-суффикс |
| `tā` | 1058 | таддхита-суффикс |
| `ja` | 461 | кṛт-основа (√jan) |
| `maya` | 421 | таддхита-суффикс |
| `pati` | 358 | **настоящий uttarapada** |
| `kara` | 331 | кṛт-основа |
| `mat` | 291 | таддхита-суффикс |
| `kāra` | 284 | кṛт-основа |
| `karman` | 274 | **настоящий uttarapada** |

То есть примерно половина верхушки — не вторые члены композитов, а вторичные суффиксы. Для любого
потребителя, который берёт этот файл как «список правых членов самас», это ловушка: фильтровать
надо явно. И наоборот — как **список деривационных баз** те же строки ценны сами по себе
(`-tva` 1246, `-tā` 1058, `-vat` 1136, `-maya` 421, `-mat` 291, `-tas` 251, `-tara` 152,
`-tama` 135 засвидетельствованных основ по разметке MW).

**Важная оговорка к пункту 2:** посессивные `-in`/`-mant` и относительные `-ika`/`-ya` в этой
разметке практически отсутствуют (`-ya` = 1, `-in`/`-ika`/`-mant` = 0) — MW оформляет их иначе.
Так что как источник для таддхиты файл покрывает продуктивную абстрактно-материальную группу и
**не** покрывает ровно те суффиксы, которые в наших собственных работах оказались проблемными.
